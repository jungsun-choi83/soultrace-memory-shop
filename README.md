# Soul Trace — The Memory Shop

소울트레이스 이용자를 위한 개인화 메모리 상품 자사몰 **프런트엔드 MVP**입니다.
첨부된 편지·키링·포토카드 시안의 아이보리 / 세이지 / 빈티지 페이퍼 분위기를 반영했습니다.

> **현재 버전은 데모입니다. 실제 결제·주문 접수·고객 계정 조회·제작 요청을 하지 않습니다.**
> 가격 외 제품 구성, 색상 옵션, 제작·배송 정책은 확정 사양이 아닙니다.

## 1. 가장 빠르게 확인

`preview.html`을 브라우저로 열면 됩니다. 이미지·CSS·JS가 포함된 **오프라인 단일 파일**입니다.
정적 미리보기 환경에서 스크립트가 제한된다면 파일을 내려받아 일반 브라우저로 열어주세요.
네트워크 연결이나 외부 폰트·라이브러리 설치 없이 디자인과 상호작용을 확인할 수 있습니다.
이 파일을 직접 수정하지 말고 아래 소스를 수정한 다음 `npm run build`로 다시 생성하세요.

## 2. Cursor에서 실행

1. 압축을 해제합니다.
2. Cursor에서 `soultrace-memory-shop` 폴더를 엽니다.
3. Node.js가 설치된 터미널에서 아래 명령을 실행합니다. 이 프로젝트는 npm 패키지 의존성이 없으므로 `npm install`이 필요 없습니다.

```bash
npm run dev
```

터미널에 표시된 `http://127.0.0.1:5173`에서 확인합니다.

```bash
npm test        # 핵심 로직 단위 테스트
npm run check   # 문법 검사 + 단위 테스트 + 빌드
npm run build   # 정적 배포용 dist/와 단일 파일 preview.html 생성
npm run preview # dist/를 로컬에서 확인
```

검증 환경: Node.js v22.16.0. 소스는 Node.js 20 이상을 기준으로 작성했습니다.
개발 서버는 localhost에서만 열리고 GET/HEAD 정적 파일만 제공합니다. 주문 API가 아닙니다.

## 3. 가격 및 상품 매핑

사용자가 제시한 가격과 구성을 아래 상품에 반영했습니다. **이 배정과 구성명은 초안입니다.**

| ID | 상품 | 판매가(원) |
|---|---|---:|
| nfc | NFC 메모리카드 | 9,900 |
| letter | 마음을 담은 편지 세트 (편지 · 엽서 · NFC 인식표) | 24,900 |
| minibook | 미니 메모리북 키링 | 49,900 |

수정 위치: `src/catalog.mjs`의 `PRODUCTS`.
우표 & 포토카드 세트는 키링·NFC 메모리카드로 교체했습니다.
NFC 메모리카드가 카탈로그 1번입니다. 편지 세트 구성은 편지 · 엽서 · NFC 인식표이며, 인식표 자리에 제공된 가죽 포토 키링 시안을 올렸습니다.
NFC 메모리카드는 NFC가 내장된 포토카드로, 생성된 편지 또는 사진을 액션으로 담아 보내는 방향입니다. 현재 데모에서는 실제 NFC 쓰기·전송을 하지 않습니다.
색상은 편지 시안의 세이지/블루, 미니북 시안의 크림/모카/세이지를 선택 UI로 표시했습니다.
실물 옵션 출시를 확정했다는 의미가 아닙니다. 미니북 이미지에는 크림 시안만 표시됩니다.

## 4. 구현된 기능

- PC/모바일 반응형 홈, 카테고리 필터, 편집 가능한 세 상품 카탈로그.
- 모달 상품 상세, 색상·수량 선택, 아이 이름·메시지·편지 입력.
- 보리의 명시적인 **예시 아카이브** 선택. 실제 로그인으로 가장하지 않습니다.
- JPG/PNG/WEBP 5MB 이하 대표 사진 한 장의 브라우저 내 리사이즈·미리보기.
- 장바구니 추가, 수정, 삭제, 수량 제한 및 합계 계산.
- 테스트 배송 정보 입력, 폼 검증, 결제가 아닌 주문 미리보기 결과.
- FAQ, 운영·개인정보·구매 안내 모달, 브라우저 데이터 삭제.
- 한/영 화면 전환. 기본 언어는 한국어이며, 영어에서도 가격은 원화(KRW)입니다.
- 네이티브 dialog의 키보드 처리와 포커스, 스킵 링크, 오류/상태 안내, reduced-motion 대응.

## 5. 데이터·결제 안전장치

- **실제 결제 호출, 주문 저장, 이메일 발송 또는 파일 업로드가 없습니다.**
- localStorage에는 상품 ID/옵션/수량/임의 항목 ID와 한/영 언어 선택만 저장합니다.
- 아이 이름·사진·편지는 탭 메모리에만 남습니다. 새로고침 후 재입력을 요구합니다.
- 배송 정보는 화면을 닫거나 미리보기를 생성하면 지우며 주문 결과에 보관하지 않습니다.
- 임의 외부 사진 URL, 원격 웹폰트, 광고 픽셀, 분석 도구, 세션 녹화를 넣지 않았습니다.
- `shippingFee: null`은 **미정**입니다. 0원/무료배송을 의미하지 않습니다.
- 상품 가격은 클라이언트 카탈로그에서 재계산합니다. **실거래에서는 반드시 서버가 다시 검증해야 합니다.**
- `SHOP.mode` 값을 바꿔도 실결제 기능이 생기지 않습니다. 별도 서버/PG 연결이 필요합니다.
- robots `noindex, nofollow`는 개발 시안용이며, 보호나 접근제어 수단이 아닙니다.

## 7. 아직 구현하지 않은 것

실제 SoulTrace 인증·아카이브 API, 개인화 원본 파일 저장, 다중 사진/최종 인쇄 편집, PG 결제,
서버 가격/재고/쿠폰/세금/배송비 계산, 실제 주문·환불·고객 주문내역, 제작사 전달,
QR/NFC, 운영자 화면, 해외 결제·배송 정책, 배포와 도메인 연결은 **미구현**입니다.
웹앱의 실제 저장소·API 계약·PG 키를 확인한 뒤 연결해야 합니다.

실판매용 약관과 개인정보처리방침은 기존 검토 문서의 미확정 정보를 채운 최종본으로 연결하세요.
이 데모의 로컬 데이터 안내는 전체 서비스의 법률 문서를 대체하지 않습니다.
