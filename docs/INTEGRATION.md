# v2 통합 문서 위치

v1의 '예시 아카이브만 연결' 구조는 v2의 이메일 확인·서버 보호 경로로 교체했습니다.

1. `ARCHITECTURE.md`: 화면과 API 구조.
2. `SOULTRACE_BRIDGE.md`: 실제 SoulTrace에 추가/매핑할 계약, 기존 미검증 기록 취급.
3. `DEPLOYMENT.md`: 키/환경설정, 단일 SQLite 배포 제약, 실판매 미연동 범위.
4. `../CURSOR_START.md`: 실제 코드베이스 조사부터 통합 검증까지의 작업 지시.

이메일 소유 확인만으로 과거에 해당 주소가 적힌 모든 기록이 본인 소유가 되는 것은 아닙니다.
최종 소유권/삭제 상태는 원 SoulTrace에서 확인합니다. 기존 사용자 DB를 임의 복제하지 마세요.

상품 가격은 유지했지만 운영 견적은 서버 권위로 다시 계산해야 합니다.
현재 장바구니 합계는 주문 미리보기이며, 배송비/세금/최종 결제액은 UNKNOWN입니다.
